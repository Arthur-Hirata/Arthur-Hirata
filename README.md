## 🚀 Projetos em destaque

### 📦 [StockFlow](https://github.com/Arthur-Hirata/StockFlow)
Sistema completo de gerenciamento de estoque: produtos, usuários, movimentações, vendas, logs e dashboard. Possui controle de acesso por função (`admin` / `user`) e o back-end recalcula os valores das vendas direto no banco, sem confiar nos dados enviados pelo front-end.
`React` `Vite` `Flask` `SQLite` `JWT`

### ⚽ [Dev-Stickers](https://github.com/Arthur-Hirata/Dev-Stickers)
Álbum digital de figurinhas inspirado na Copa do Mundo, criado para praticar autenticação com JWT e aprofundar meus conhecimentos em banco de dados.
`JavaScript` `Python` `JWT`

### 🖥️ [Velocity Store](https://github.com/Arthur-Hirata/Velocity-Store)
Meu primeiro projeto Full Stack: um e-commerce de peças de computador com cadastro e login, carrinho, senhas com hash e painel administrativo (dashboard, CRUD de produtos e gestão de usuários).
`HTML` `CSS` `JavaScript` `Python` `SQLite`

### 🌊 [Flowly](https://github.com/Arthur-Hirata/Flowly)
Landing page de uma plataforma fictícia de produtividade, desenvolvida para praticar componentização e tipagem no front-end.
`React` `TypeScript` `Tailwind CSS`

### 🚦 [RateLimit-API](https://github.com/Arthur-Hirata/RateLimit-API)
API simples criada para estudar e testar o funcionamento de *Rate Limiting* baseado no endereço IP.
